# SEIR Epidemiology Model

## Overview
This project implements a classical SEIR (Susceptible-Exposed-Infected-Recovered) epidemiological model.  
It allows users to explore different disease spread scenarios and intervention strategies.

## Dataset
- Synthetic / simulated epidemiological data (generated in the notebook)

## Methods
- SEIR compartmental model
- Python implementation using NumPy and Matplotlib
- Interactive scenario analysis with IPyWidgets

## Key Insights
- Visualization of epidemic waves
- Impact of varying transmission rates and recovery rates
- Understanding of epidemic dynamics and control strategies

## Tools & Skills
Python, NumPy, Matplotlib, IPyWidgets, Epidemiological Modeling
